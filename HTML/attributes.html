What is an Attribute

An attribute is extra information attached at the opening tag of an element to:
Describe it - give more details about it
Control it - change how it behaves or looks
Identify it - give it a unique name so it can be found
Attributes are always in name="value" pairs

Common Attributes

  1. id - gives an element a unique identifier (name)
  2. class - groups diff elements by giving them a commong identifier
  3. style - Adds inline CSS directly to single element(not recommended for large projects)
  4. title - Adds extra information that shows as a small tooltip when you hover over the element.
  5. href - specifies the URL of a link (used in <a> tags)
  6. src - specifies the source URL of an image (used in <img> tags)
  7. alt - provides alternative text for an image if it cannot be displayed (used in <img> tags)
  8. width and height - specify the dimensions of an image or other elements (used in <img> and <video> tags)
  9. type - specifies the type of input element (used in <input> tags)
  10. value - specifies the value of an input element (used in <input> and <option> tags)
