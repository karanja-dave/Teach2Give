# teach2Give

This repository documents my learning journey across different technical skills.  
Each skill has its own folder that contains both **basic/fundamental starter codes** and **mini-projects** to demonstrate what I’ve learned.  

---

##  Repository Structure

``teach2Give/
│
├── Skill-1/
│ ├── basics/ # Fundamental exercises & starter files
│ └── mini-projects/ # Applied projects
│ ├── project-1/
│ └── project-2/
│
├── Skill-2/
│ ├── basics/
│ └── mini-projects/
│
└── README.md``
---

- **basics folder** → contains practice code, small snippets, and starter files used to understand the fundamentals of each skill.  
- **mini-projects folder** → contains applied projects that reinforce concepts through practical builds.  
- **project-specific folders** → each project has its own folder with all the files required to run it.
